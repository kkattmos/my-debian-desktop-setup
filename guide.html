debian-13.7.0-amd64-netinst.iso · GNOME 48 · LUKS2 + Btrfs

A lean Debian 13 laptop with tiling GNOME

A minimal Debian “trixie” install next to Ubuntu. It runs GNOME with tiling, Ly as the login screen, your course tools, and a Neovim, ZSH and Docker setup for development. The system disk is encrypted with LUKS2 and uses Btrfs with zstd compression. Every package size below comes from Debian 13’s package index, including dependencies.

Install, step by step

Keep this page open on your phone during the install. It uses the normal graphical installer, and the command blocks have copy buttons.

1

Prepare from Ubuntu Ubuntu

00-ubuntu-prep.sh shows what is on p3 and asks before continuing. It downloads the ISO and checks its SHA512 checksum and Debian’s signature. It stashes the kit and your Packet Tracer .deb in ~/debian13-stash, then writes the USB after you type YES.

bash debian13-setup/00-ubuntu-prep.sh

Also download the STM32CubeIDE 1.9.1 generic Linux installer from st.com (myST login → Get Software → version 1.9.1 → “STM32CubeIDE-Lnx”) into ~/debian13-stash.

Before you start: back up anything on p3. Write down your LUKS passphrase using US-keyboard characters only; the boot prompt can’t type Thai.
2

Boot the USB → Graphical install Installer

The normal installer is all you need. You only type commands after the first boot: the Btrfs subvolumes and compression are set up by 10-system.sh. Secure Boot can stay on, since Debian’s shim is signed.

Manual partitioning

  1. Select #3 (185.5 GB ext4) → Delete the partition.
  2. In that FREE SPACE → new partition → size: the maximum shown minus 1 GB (e.g. 184.5 GB) → Beginning → Use as: physical volume for encryption (Erase data: no is faster; yes is more thorough). It becomes #3.
  3. In the 1 GB FREE SPACE left at the end → new partition, full size → Ext4, mount point /boot. This order matters: the encrypted partition must sit directly after Ubuntu so the two can merge later.
  4. Configure encrypted volumes → create → pick that partition → finish → enter the passphrase twice.
  5. At the top of the list, under the heading Encrypted volume (nvme0n1p3_crypt), select the #1 line beneath it → Use as btrfs, mount point /, mount option noatime. Not the #3 … crypto line under your NVMe drive: that one is the raw encrypted partition, and selecting it gives “No modifications can be made … in use as physical volume for encrypted volume”. If the heading is missing, finish step 4 first.
  6. #1 (EFI, 1 GB) must show EFI System Partition and not be formatted, because Ubuntu’s bootloader lives there too.
  7. #6 (Ubuntu swap) → Use as: do not use. Otherwise encrypted data could leak to unencrypted swap.
  8. #2, #4, #5: no mount point, not formatted. Finish partitioning → it warns there’s no swap → continue → write changes.
3

First boot: system script Debian, text console

After the installer’s reboot you get the disk-password prompt, then a text login. Copy the stash from Ubuntu’s partition (read-only), then run the system script twice, with a reboot in between.

sudo mount -o ro /dev/nvme0n1p2 /mnt
cp -r /mnt/home/<ubuntu-user>/debian13-stash ~ && sudo umount /mnt

sudo bash ~/debian13-stash/kit/10-system.sh $USER    # run 1: Btrfs layout, ~2 min
systemctl reboot
sudo bash ~/debian13-stash/kit/10-system.sh $USER    # run 2: everything else, 10–20 min
sudo bash ~/debian13-setup/38-grub-theme.sh          # optional: Space Isolation GRUB theme
systemctl reboot

Run 1 turns on zstd compression and compresses what the installer wrote. It creates the @home, @snapshots, @var_log, @var_cache and @docker subvolumes, copies the current data into them and adds them to /etc/fstab. It checks the new fstab and stops before the reboot if anything looks wrong; the installer’s original is kept as /etc/fstab.installer-bak.

Run 2 checks that the subvolumes are mounted and deletes the old copies hidden underneath them. Then it sets up APT (no recommended packages, non-free-firmware); adds the Docker, ONLYOFFICE and Tailscale repos; installs the packages in one go (all 93 names checked against Debian 13); sets up zram, Snapper, GRUB with os-prober, libncurses5 from Debian 12, and PhotoPrism; builds Ly; and moves the installer’s Wi-Fi to NetworkManager.

4

Log in through Ly → GNOME, then Wi-Fi and user setup GNOME terminal

bash ~/debian13-setup/20-wifi.sh     # ChulaWiFi + eduroam + home SSIDs, passwords asked, stored root-only
bash ~/debian13-setup/30-user.sh     # zsh, fonts, Neovim+LazyVim, Tiling Shell, Ptyxis look, Tailscale login, SeaDrive, PhotoPrism

30-user.sh gets a SeaDrive token from your server with your password once (the password isn’t saved). It enables seadrive.service and turns on lingering, so the drive mounts at boot even before you log in. Log out and back in afterwards so zsh, the new groups and the tiling extension take effect, then run bash ~/debian13-setup/32-check.sh to confirm everything took.

Daily use

The few commands and keys you’ll actually use.

Record the screen

CtrlShiftAltR starts or stops a full-screen recording, or press Print and switch to the camera to record an area. Files go to ~/Videos/Screencasts as WebM, without audio. For audio, run sudo apt install kooha.

Tiling

Hold Ctrl while dragging a window to snap it into a layout. Auto-tiling and keyboard moves are in Extension Manager → Tiling Shell. Workspaces: Super+1–4, and add Shift to move a window there.

Terminal look

Ptyxis → Ctrl+, → Profiles changes the palette and transparency. cava shows audio bars, and fastfetch shows system info (set FASTFETCH_ON_START=0 in ~/.zshrc to stop it opening every tab). Its layout lives in ~/.config/fastfetch/config.jsonc.

Docker & PhotoPrism on/off

svc docker on · svc docker off
svc photoprism on → http://localhost:2342
photoprism index works in any terminal.

SeaDrive

Starts at boot automatically. svc seadrive status shows its state; the log is at ~/.seadrive/logs/seadrive.log. The cache limit is set in ~/.config/seadrive/seadrive.conf.

Notebooks in Neovim

Open x.ipynb: text cells are rendered, code cells are boxes, and the kernel starts by itself. Alt+Enter runs a cell and moves to the next, \ra runs all, ]c/[c jump between cells, \cb adds a cell. Open notebooks with nb x.ipynb (or from Files): that uses kitty, which draws plots under the cell. Ptyxis can’t show images, so plots there open in the image viewer. To use a project venv: pip install ipykernel && python -m ipykernel install --user --name proj.

Updates & snapshots

update runs apt with an automatic before/after snapshot. snaps lists snapshots. Thai keyboard: Super+Space.

Rolling back a bad update

Boot the Debian USB → Advanced → Rescue mode (or any live USB). Then:

cryptsetup open /dev/nvme0n1p3 root     # p2 once you’ve merged Ubuntu’s space
mount -o subvolid=5 /dev/mapper/root /mnt
ls /mnt/@snapshots                     # pick snapshot N (see `snaps`)
mv /mnt/@rootfs /mnt/@broken
btrfs subvolume snapshot /mnt/@snapshots/N/snapshot /mnt/@rootfs
reboot

If the bad update included a kernel, run sudo apt install --reinstall linux-image-amd64 after booting, because /boot isn’t part of the snapshot.

When you drop Ubuntu

An encrypted partition can only grow at its end, and Ubuntu sits before Debian. So instead of growing Debian backwards, the script moves Debian onto p2 and then grows p2 forward over the old partition. You end up with one encrypted partition of about 650 GB, and Debian keeps running the whole time.

sudo bash ~/debian13-setup/90-absorb-ubuntu.sh    # asks you to type ERASE-UBUNTU
  1. Checks that Debian’s encrypted partition starts right after p2. If it doesn’t (for example, /boot ended up in between), it stops without changing anything.
  2. Removes Ubuntu’s boot entry and EFI/ubuntu, then encrypts p2. Use the same passphrase, so one prompt unlocks both partitions while data is being moved.
  3. Switches /etc/fstab to the Btrfs filesystem UUID, which never changes. The old /dev/mapper/… name disappears after the move.
  4. Adds p2 to the filesystem, then runs btrfs device remove on the old partition. Btrfs copies your data onto p2 while you keep working.
  5. Deletes the old partition and grows p2 over the gap (growpart → cryptsetup resize → btrfs filesystem resize).
Safe to interrupt: each step checks whether it’s already done, so after a crash or reboot you just run the script again. Before every change to /etc/crypttab, it rebuilds the boot image and checks that the image will unlock the right partitions. If that check fails, it stops and tells you not to reboot.

Moving the data takes a few minutes for about 20 GB on NVMe. If you’d rather keep two partitions, --join-only just adds p2 to the filesystem with no copying.

Things that bite

Each of these was checked during research and is handled by the scripts.

Installer Wi-Fi turns into ifupdown

With no desktop selected, the installer writes Wi-Fi into /etc/network/interfaces, and NetworkManager then ignores the card. 10-system.sh copies it into a NetworkManager profile and comments the lines out.

Debian grabs Ubuntu’s swap

Two things switch on Ubuntu’s unencrypted p6. The installer may add it to /etc/fstab, even when it’s set to “do not use”; run 1 of 10-system.sh comments it out and drops the resume setting. systemd also turns on every “Linux swap” partition by itself, fstab or not, so 10-system.sh masks systemd-gpt-auto-generator (on an existing install, run sudo bash 34-no-ubuntu-swap.sh). p6 itself is untouched, so Ubuntu keeps its swap. 32-check.sh should show only /dev/zram0.

Ly isn’t packaged

It isn’t in Debian 13 or sid. It needs Zig 0.16.0 exactly for v1.4.1 (Ly 1.5 will need Zig 0.17). To update later, rebuild with zig build installnoconf.

Ly leaks TERM=linux

Ly starts GNOME from a text console, so the whole desktop inherits TERM=linux and the terminal passes it on. Powerlevel10k then thinks the terminal has 8 colours and no Unicode, and p10k configure skips most of its questions. The .zshrc switches it back to xterm-256color inside graphical terminals.

libncurses5 is gone in Debian 13

CubeIDE’s bundled arm-none-eabi-gdb needs libncurses.so.5. The script installs Debian 12’s libtinfo5 and libncurses5 (6.4-4, checksums pinned), the same fix your Ubuntu install uses.

Your Seafile server is on Tailscale

Your current SeaDrive account points at a 100.x Tailscale address. Tailscale is installed and tailscale up runs before the first SeaDrive start. Both run at boot.

PhotoPrism × SeaDrive

If PhotoPrism’s originals folder is inside ~/SeaDrive, indexing reads every photo, so SeaDrive downloads them all into its cache. Keep originals local (default ~/Pictures) or raise the cache limit.

Two GRUBs

An Ubuntu update can make Ubuntu’s GRUB the default again. Use the laptop’s boot menu key, or sudo efibootmgr -o to put Debian first.

Docker group = root

Being in the docker group is effectively root access. That’s acceptable on a single-user laptop; remove yourself with gpasswd -d $USER docker if you’d rather type sudo.

ChulaWiFi keeps asking for the password

The login fails at the TLS step: Chula’s server only offers TLS 1.0/1.1. 20-wifi.sh sets 802-1x.phase1-auth-flags 0x60 and 802-1x.openssl-ciphers DEFAULT@SECLEVEL=0 on both profiles. To see the real error, run /usr/sbin/wpa_cli -i wlp2s0 while connecting (look for local TLS alert).

ChulaWiFi certificate check

This copies your Ubuntu profile exactly (domain match, no CA bundle). If it still connects with 802-1x.system-ca-certs yes, turn that on for a stronger check.

Files in the kit

Everything is in the debian13-setup folder. Run the scripts in number order.

  • 00-ubuntu-prep.sh checks p3, downloads and verifies the ISO, stashes the installers, writes the USB
  • 10-system.sh sets up the whole system as root, in two runs (Btrfs layout first, then repos, packages, Ly, zram, Snapper, Docker off)
  • 20-wifi.sh creates the ChulaWiFi + eduroam (PEAP) and home WPA2 profiles
  • 30-user.sh sets up zsh, the Nerd Font, the Sarabun Thai font, Neovim/LazyVim, Tiling Shell, the terminal look, Tailscale, SeaDrive and PhotoPrism
  • 31-gnome-settings.sh installs Tiling Shell and writes the GNOME settings as system defaults, and resets any value GNOME saved for you at first login that would hide them (run it in a GNOME terminal; called by 30)
  • 32-check.sh prints a read-only status report of the session, shell, GNOME settings and services
  • 33-clean-root-leftovers.sh removes what an accidental sudo bash 30-user.sh left in /root (run with sudo; the user scripts now refuse to run as root)
  • 34-no-ubuntu-swap.sh stops Debian from switching on Ubuntu’s unencrypted swap partition (run with sudo; Ubuntu’s own use of it is unchanged)
  • 35-thai-font.sh installs Sarabun (Google Fonts) and makes it the Thai fallback for sans-serif and serif, so Thai in Firefox, Discord and GNOME no longer falls back to Loma. Latin text and monospace are unchanged (no sudo; called by 30)
  • 36-terminal-look.sh installs Ptyxis, fastfetch and cava, and sets the Ptyxis profile (Tokyo Night, 88% opacity, Nerd Font) plus the fastfetch and cava configs. Ptyxis becomes the terminal apps open. Safe to rerun (no sudo unless packages are missing; called by 30)
  • 38-grub-theme.sh installs the Space Isolation GRUB theme (1920×1080 release, sha256-checked) and uses its picture as the background behind “Loading Linux …” too, instead of Debian’s blue one. It checks grub.cfg before you reboot (optional, run with sudo, safe to rerun)
  • 40-stm32cubeide.sh installs CubeIDE 1.9.1 with the Wayland wrapper and udev rules
  • 41-packettracer.sh installs Packet Tracer 9 from the Ubuntu .deb
  • 90-absorb-ubuntu.sh later merges Ubuntu’s p2 and Debian into one encrypted partition while Debian runs
  • dotfiles/ holds zshrc, the fastfetch and cava configs, the LazyVim plugins (notebook, web) and the systemd user units
