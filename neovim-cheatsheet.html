Modes

NORMALEsc move & run commands
INSERTi a o type text
VISUALv V Ctrl+v select
COMMAND: run :w, :q…

Save & quit

Ctrl+sSave lazy
:w :wqSave / save and quit
:q :q!Quit / quit and discard changes
Spc q qQuit everything lazy
:e pathOpen a file

Move

h j k lLeft · down · up · right
w b eNext word · back a word · word end
0 ^ $Line start · first char · line end
gg G :42Top · bottom · go to line 42
{ }Previous / next blank line (paragraph)
%Jump to the matching bracket
Ctrl+d Ctrl+uHalf a page down / up
fx txTo / just before char x on the line; ; repeats
s + 2 charsJump anywhere on screen (flash) lazy
Ctrl+o Ctrl+iJump back / forward in history

Start typing

i aInsert before / after the cursor
I AInsert at line start / end
o OOpen a new line below / above
EscBack to Normal mode

Edit

xDelete the character under the cursor
dd yy ccCut · copy · replace the whole line
p PPaste after / before
u Ctrl+rUndo / redo
.Repeat the last change
JJoin the line below onto this one
>> <<Indent / outdent
gccToggle comment on the line
~Flip upper/lower case

y and p use the system clipboard (LazyVim default).

The grammar

[count] verb target → d2w
d c yVerbs: delete · change · yank (copy)
> < gcVerbs: indent · outdent · comment
iw awInside word / word + space
i" i( i{Inside quotes / parens / braces
it ipInside HTML tag / paragraph
ciwReplace this word
di( ci"Empty parens · retype a string
yap >ipCopy paragraph · indent block
dt,Delete up to the next comma

Select (Visual)

Jupyter notebooks (your setup)

nvim file.ipynb opens as Python; cells start with # %%
\miStart a kernel (do this first)
\rcRun the current cell
\rlRun the current line
\r (Visual)Run the selection
\rrRe-run the cell
\ro h dOutput: open · hide · delete

With a kernel running, :w saves outputs into the .ipynb.
